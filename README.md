**Context-aware sentence classification on BIORC800.** Compared target-only inputs with neighbouring-sentence context across PubMedBERT, BioLinkBERT and ClinicalBERT: 18 fine-tuning runs, three random seeds per model and condition, using preserved official data splits.

| Model | Target-only mean test Micro-F1 | Context mean test Micro-F1 |
|---|---:|---:|
| BioLinkBERT | 87.111% | 90.864% |
| PubMedBERT | 87.228% | 90.763% |
| ClinicalBERT | 85.854% | 89.619% |

These are means across three seeds. BioLinkBERT’s highest individual-seed context result was 91.183% Micro-F1. Do not present that peak as the mean, accuracy, Macro-F1 or a general state-of-the-art claim.

Earlier work compared BERT and SciBERT on PubMed RCT; on the evaluated 20,000-example subset, SciBERT achieved 85.65% accuracy versus BERT’s 84.20%. This is a separate experiment and metric from BIORC800.
